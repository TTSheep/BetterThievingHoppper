
# Better Thieving Hopper
此项目是杀戮尖塔2mod项目
本 Mod 修改了《杀戮尖塔2》中 **偷窃草蜢（Thieving Hopper）** 的偷牌优先级。

This mod changes the card-stealing priority of the **Thieving Hopper** in Slay the Spire 2.

## 偷牌优先级 / Card-Stealing Priority

修改后的偷牌优先级如下，数字越小，优先级越高。

The modified card-stealing priority is listed below. A lower number indicates a higher priority.

### 新增优先级 / New Priorities

1. 不带虚无的诅咒牌  
   Curse cards without Ethereal.

2. 带虚无的诅咒牌  
   Curse cards with Ethereal.

3. 没有附魔的初始牌  
   Starter cards without enchantments.

4. 有附魔的初始牌  
   Starter cards with enchantments.

### 原版优先级 / Vanilla Priorities

当没有卡牌满足上述四个新增优先级时，将按照原版偷牌逻辑继续判断。

If no cards match the four new priorities above, the game falls back to the vanilla card-stealing logic.

   Uncommon cards without the Imbued enchantment.

6. 没有注能附魔的白卡、金卡与事件卡（如异鸟扑击）  
   Common, Rare, and Event cards without the Imbued enchantment (e.g., Bird Strike).

7. 没有注能附魔的基础牌和任务牌（如藏宝图）  
   Basic and Quest cards without the Imbued enchantment (e.g., Treasure Map).

8. 有注能附魔的牌和先古牌  
   Cards with the Imbued enchantment and Ancient cards.
